# 🌤️ ATMOS — Weather App

A modern, responsive weather application built with **HTML, CSS, and JavaScript**, using the **OpenWeatherMap API** to display real-time weather information for cities around the world.

## 🚀 Live Demo

🔗 **[View ATMOS Weather App](https://weather-app-lac-nu-70.vercel.app/)**

## 💻 GitHub Repository

🔗 **[View Source Code](https://github.com/pratyusha8283/Weather-App)**

## ✨ Features

* 🌍 Search weather by city
* 🌡️ Real-time temperature
* 💧 Humidity information
* ☁️ Current weather condition
* 💨 Wind speed
* 🌡️ Feels-like temperature
* 🔎 City suggestions while typing
* ⚡ Fast API-based weather search
* 📱 Responsive design for desktop and mobile
* 🎨 Modern dark, premium UI
* ⌨️ Supports searching using the Enter key
* ❌ User-friendly error handling

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling, responsive design and animations
* **JavaScript (ES6+)** — Application logic and API integration
* **Fetch API** — Fetching weather data
* **OpenWeatherMap API** — Real-time weather information
* **Vercel** — Deployment
* **GitHub** — Version control and source code hosting

## 🔑 API

This project uses the **OpenWeatherMap API** to retrieve current weather data based on the searched city.

API endpoint used:

```text
https://api.openweathermap.org/data/2.5/weather
```
